# Snake
## (A JavaFX project created by Parker Hubley, Elijah Story, and Carter Jordan)
## About the Game
- The original game was made by Taneli Armanto in 1997.
- In snake, the player controls a snake, going up, down, left, and right around the map eating apples. After a snake eats an apple, it becomes longer and spawns another apple. The snake dies if it runs into a wall, or another part of the snake.
- We decided to make this game into a functional Java FX project, with many features.

## Apple
- At the start of the game and every time a snake eats, an apple is spawned randomly on the map.
- After it is eaten, it updates the score.
## Snake
- Can move with arrow keys.
- After every apple is eaten, the snake’s length becomes one longer.
## Layout
- The grid consists of a 30 by 30 layout, creating a big but not too big area for the snake to move around.
- The aesthetics of the project are customized, making a unique combination of dark purple and cyan creating a neon vibe.
- The project updates with the tick, which keeps the snake going.
